# 풍수해 업무 분류와 원문 근거

기준 문서는 밀양시 「풍수해(태풍·호우, 대설) 재난」 현장조치 행동매뉴얼(2026. 6.)입니다. 업무 제목과 FW/TR/SN 번호는 화면 탐색용 편집 분류입니다. 공식 업무 번호, 지휘 순서 또는 새로운 조치 지침을 뜻하지 않습니다.

| 재난 선택 | 표시 업무 | 수록 수 |
|---|---|---:|
| 산불 | 산림청 WF-001~WF-012 | 12 |
| 태풍·호우 | 태풍 TR-001~TR-004, 호우 TR-005~TR-008, 풍수해 공통 FW-001~FW-011 | 19 |
| 대설 | 대설 SN-001~SN-004, 풍수해 공통 FW-001~FW-011 | 15 |

풍수해 공통 FW 업무는 한 벌로 보관하고 두 기상 재난에서 조회합니다. 태풍·호우 전용 업무는 대설에, 대설 전용 업무는 태풍·호우에 표시하지 않습니다. 산불은 별도 산림청 문서와 원문 근거를 사용합니다.

| 번호 | 탐색용 업무명 | 분류 |
|---|---|---|
| FW-001~FW-002 | 사전대비·기상감시, 대비 총괄·취약시설 예찰 | 공통 |
| FW-003~FW-004 | 초기 대응·상황보고, 초기 응급복구·홍보 | 공통 |
| FW-005~FW-011 | 비상 상황관리, 구호, 통신, 시설, 교통, 의료·구조, 환경정비 | 공통 |
| TR-001~TR-004 | 태풍 징후감시·대비, 초기 대응, 비상 대응·대피, 수습·복구 | 태풍 전용 |
| TR-005~TR-008 | 호우 징후감시·대비, 초기 대응, 비상 대응·대피, 수습·복구 | 호우 전용 |
| SN-001~SN-004 | 대설 징후감시·제설 준비, 초기 대응·제설 가동, 비상 대응·대피, 수습·복구 | 대설 전용 |

조치 본문은 HWPX의 `Contents/section3.xml` 문단에서 추출했습니다. 각 조치는 원문 인용과 XML 요소 위치·문단 ID·원천 파일 SHA-256을 가집니다. 줄바꿈과 공백만 정규화했습니다. 그래프 연결선은 업무에 포함된 조치를 나타내며 순서를 뜻하지 않습니다. 경보·특보 등 적용 조건은 각 전용 업무에 별도로 표시합니다.

대설 원문의 “행정시장” 표기는 그대로 남겼습니다. 밀양시 업무에 적용할 직위는 담당 부서의 확인이 필요해 SN-003에 `[확인 필요]`로 표시합니다. 원본 HWPX 전체와 비상연락망은 저장소와 서비스에 포함하지 않았습니다.
